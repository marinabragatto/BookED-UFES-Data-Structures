# BookED

A book tracking and recommendation system written in C, built for the Data Structures course at UFES.

Readers can mark books as read or wanted, recommend books to each other, find books they have in common and check whether two readers have an affinity.

Authors: Marina Bragatto, Thais Brandão

The program reads the books, the readers and a list of commands from text files, runs the commands in order and writes the results to an output file. The data is stored in a generic *doubly linked list*.

## Build and run

```
make
./<executable>
```
